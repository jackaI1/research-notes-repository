# Deposition run notes, week 1

Three coating runs were made at the same chamber setting. The film thickness reading from the profilometer varied more between runs than within a run, which points to the substrate holder rather than the deposition. One run had an outlier that was caused by a loose sensor cable. The team decided to re-seat the cable and repeat the run before drawing any conclusion. Next step: measure thickness at five points on each substrate.
